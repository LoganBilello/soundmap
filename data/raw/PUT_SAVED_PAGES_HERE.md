# Manually saved Every Noise pages

Save these TWO pages here. everynoise.com/robots.txt blocks automated access,
so a person saves them by hand and the scripts only read local files.

  engenremap.html   <- https://everynoise.com/engenremap.html   (~3.5 MB)
  countries.html    <- https://everynoise.com/countries.html    (~965 KB)

How to save each one:
  1. Open the URL in Chrome or Edge.
  2. Press Ctrl+S.
  3. Set "Save as type" to "Webpage, HTML Only".
  4. Save into this folder with the exact filename above.

These are optional. The globe already draws without them. They add the
preview clips, the example artists, and the 200-country ranking.
